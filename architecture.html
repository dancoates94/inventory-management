Factory Inventory Management System

Architecture overview — Vue 3 frontend · FastAPI backend · in-memory mock data

Tech Stack

Frontend

Vue 3 + Vite

Composition API, Vue Router 4, Axios. Dev server on port 3000. No CSS framework — custom SVG charts and CSS Grid layouts.

Backend

FastAPI + Uvicorn

Single-file main.py, 14 REST endpoints, Pydantic models for validation, CORS open for local dev. Port 8001.

Data

In-memory JSON

No database. JSON files in server/data/ loaded once at startup by mock_data.py and filtered in Python.

System Architecture

Client
Vue 3 SPA:3000
7 views, 10 modal components, useFilters / useI18n composables. Built & served by Vite.
→
API client
api.js (Axios)
Centralized HTTP client. Builds URLSearchParams from active filters, calls http://localhost:8001/api/*.
→
Server
FastAPI:8001
main.py — routes, filter functions (apply_filters, filter_by_month), Pydantic validation.
→
Data layer
mock_data.py
Loads 7 JSON files from server/data/ into module-level Python objects at import time. No persistence.
No database: all "queries" are Python list comprehensions over data loaded once at process start. Restarting the backend resets any mutated state (e.g. created purchase orders).

Request / Data Flow

Example: user selects a filter (e.g. warehouse or period) on the Dashboard.

1User changes a filter in FilterBar.vue
→
2Shared singleton state updates in useFilters.js
→
3View's watch() fires, calls loadData()
→
4api.js builds query params, sends GET request
→
5FastAPI route applies apply_filters() / filter_by_month()
→
6Result validated against Pydantic model, returned as JSON
→
7Vue stores response in a ref; computed properties derive KPIs/charts
→
8Template re-renders reactively

Key File Locations

client/src/views/*.vue

7 pages: Dashboard, Inventory, Orders, Demand, Spending, Backlog, Reports.

client/src/components/*.vue

Filter bar, language switcher, profile menu, and 6 detail modals.

client/src/composables/

useFilters.js (shared filter state), useI18n.js (en/ja), useAuth.js.

client/src/api.js

Single Axios client used by every view to talk to the FastAPI backend.

server/main.py

FastAPI app: routes, filter helpers, Pydantic models, CORS config.

server/mock_data.py + server/data/*.json

Data loading and the underlying mock dataset.
